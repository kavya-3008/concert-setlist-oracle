Concert Setlist Oracle

Tours are more regular than they look: a core set every night, plus a few rotating slots. This predicts the next setlist from past shows and flags which songs are "due" as a surprise.

Demo data is a synthetic tour by a fictional band (24 shows). Source on GitHub.
